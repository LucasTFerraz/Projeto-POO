# Pré-aula 1 — Sprint de fundamentos + if/elif + for/while + strings

## O robô até aqui

Ainda não existe — esta é a aula zero do robô. Numa aula só, ele vai nascer com uma posição
`(x, y)` numa grade 10 × 10, aprender a *decidir* se pode andar antes de dar um passo, e por
fim passar a executar uma sequência inteira de comandos sozinho.

## O problema que vamos resolver

Imagine que o robô recebe um programa com 50 comandos — "anda 3 casas", "vira à esquerda",
"anda mais 2"... Rodar o programa comando por comando, uma execução por vez, não escala. Como
fazer o robô ler a lista inteira e executar um comando atrás do outro, sozinho, até acabar?

## Aquecimento (5 min — faça antes de entrar na sala)

Você entrou neste curso por prova de programação. Sem consultar nada, escreva de memória:

1. Uma linha de Python que armazena o número `42` numa variável chamada `resposta`.
2. Uma linha que imprime exatamente `A resposta é 42`, usando a variável que você criou (dica:
   se você já usa outra linguagem, tente lembrar como Python monta texto com valor — o nome da
   técnica começa com "f").

Não precisa ser perfeito — o objetivo é ativar o que você já sabe antes de entrar na sala.
